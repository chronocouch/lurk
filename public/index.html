How it works — it's set up per faction

  1. One person sets it up. A leader or officer connects a Torn API key with Faction access. Lurk detects your faction and starts building its activity picture — only that one key does the polling.
  2. Teammates just sign in. When a member signs up, their own key confirms they're in the faction and they're added automatically as a viewer. No extra setup, no second key stored.
  3. It sharpens over time. Patterns fill in over roughly 1–2 weeks of data — the longer it runs, the better the predictions during a war.

What you'll need

  • A Torn account, and to be a member of a faction
  • A Torn API key with Faction access — create one here

Free to use — nothing is paywalled. Your API key is stored server-side, used only to poll the Torn API, and is never shown to other users. New email sign-ups verify their address first.
